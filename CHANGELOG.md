# Changelog

## 0.1.0

- Record property damage or a utility meter reading during a key handover.
- Render both forms from bundled A2UI 1.0 messages with a single Material 3 renderer.
- Validate entries, review a summary, and share it as plain text using Android's Sharesheet.
- Run the demo offline on Android 8.0 or later.
- Choose the entry type explicitly and keep draft values when switching forms.
- Use a slate-blue brand header and form-specific icons to identify the app and entry types.
- Enter damage details with example placeholders, inline errors, and a description character counter.
- Inspect the local A2UI message used to render each form directly in the app.
- Fix a release-only startup crash caused by scoped R8 optimization.
